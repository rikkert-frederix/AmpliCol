# NLO extension audit ledger

Last updated: 2026-09-01

This is the living issue ledger for the `subtracted_real` branch. It covers the
Born, local real subtraction, integrated I/P/K terms, phase-space generation,
adaptive integration, generated amplitude libraries, diagnostics, tests, and
build workflow. `FIXED` means a concrete defect has been corrected in the
working tree. `OPEN` means the limitation or risk remains. `INVESTIGATE` means
there is a credible failure mode but not yet enough evidence for a safe physics
change.

The missing virtual term is accepted project scope, not an accidental omission.
Unless stated otherwise, the implementation is leading-colour and uses
massless initial-state partons.

## Open and investigated issues

| ID | Severity | Status | Area | Finding and required follow-up |
|---|---|---|---|---|
| NLO-O001 | High | OPEN, mitigated | Process completeness | `process_list.py` omits three-quark-line states unless `--include_3qqbar` is supplied. For Born processes with two quark lines this can omit physical real `g -> q qbar` sectors while I/P/K use the configured full `nf`, biasing the result. Initialisation emits a prominent warning and an affected Born-emitter example, but still permits deliberately restricted process lists. Decide whether combined NLO mode should make this fatal or automatically request all supported required sectors. |
| NLO-O002 | Expected | OPEN by design | Virtual | The one-loop virtual contribution is not implemented. Reports explicitly label the returned finite subtotal as `B+(R-D)+I0+P+K`; it is not a complete NLO prediction. |
| NLO-O003 | Medium | OPEN, documented | Massive subtraction | Integrated kernels require a massless unresolved parton and massless incoming legs. Supported massive cases are restricted to final-state Q -> Qg emitters and specified massive spectators/topologies. Other massive histories stop at initialisation. |
| NLO-O004 | Expected | OPEN by design | Colour accuracy | Event generation and subtraction are leading-colour. The existing LO reweighter does not provide a demonstrated full-colour correction for the NLO real/integrated combination. |
| NLO-O005 | Medium | OPEN | Validation | There is no automated independent end-to-end benchmark of `R-D+I+P+K` against a second NLO implementation, nor a statistically controlled full-run alpha-independence suite across representative massless/massive processes. Kernel goldens, pole reconstruction, local limit diagnostics, and smoke tests are useful but do not close this gap. |
| NLO-O006 | Medium | OPEN | Performance | `integrated_endpoint` and `integrated_beam` scan the complete integrated-history registry and redo flavour/order matching for every Born copy and Monte Carlo point. Pre-index histories by Born group/process/copy/beam and cache point-independent kernel metadata. Repeated whole-set PDF evolution was fixed separately as NLO-F015. |
| NLO-O007 | Medium | OPEN, documented | Memory/performance | The integrator retains a large event sample and can require several GB for high multiplicity. There is no grid-pack/resume mode, so splitting runs can undersample rare regions and one large run can exhaust memory. |
| NLO-O008 | Low | OPEN | Scale variation | The integrated formulae accept distinct `mu_R` and `mu_F`, but the executable currently sets `scale_fac=scale_ren`. Independent scale variation is not exposed. |
| NLO-O009 | Low | OPEN, dormant | Amplitude representation | The compile-time `use_real_gluons` path is fixed to false by default and is incomplete: generated-library emission, Weyl interactions, two-quark-line cases, and same-flavour reconstruction reject it. The supported complex-gluon path is used by all audited NLO builds. Either remove this experimental branch or finish it before exposing the option. |
| NLO-O010 | Low | OPEN, documented | Multichannel performance | HAAG and GenPT do not implement inverse maps. Their colour-singlet multichannel combination therefore uses an unbiased uniform `1/N` partition rather than point-dependent multiple-importance densities, potentially increasing variance for disparate partner channels. Implement inverse maps to recover the optimized weighting. |
| NLO-O012 | Low | OPEN | Flavour schemes | Combined subtraction accepts only 1FS through 5FS. Six-flavour PDFs/initial-state top treatments are unsupported. |
| NLO-O013 | High | OPEN, detected | Four-quark-line real sectors | The matrix-element implementation supports at most three q-qbar lines. A Born state that already has three lines therefore cannot include its four-line real `g -> q qbar` sectors, even with `--include_3qqbar`, and cannot provide a complete full-`nf` NLO result. Initialisation and the README now identify this case explicitly instead of suggesting an ineffective flag. Implement a four-line colour basis before treating such processes as complete. |

## Defects fixed in this audit

| ID | Severity | Status | Area | Defect and correction |
|---|---|---|---|---|
| NLO-F001 | High | FIXED, tested | Amplitudes | Same-flavour operations 4--7 constructed `complex(4)` values with default-kind `cmplx`, then widened them to `complex(8)`. Both the runtime evaluator and generated-library source now request `kind=8`. Direct and generated Fermi-statistics regressions pass. |
| NLO-F002 | High | FIXED, tested | Floating-point safety | The default `-ffast-math` made explicit `ieee_is_finite` guards eligible to fold away and allowed unsafe reassociation in the delicate `R-sum(D)` cancellation. | NLO-F003 | High | FIXED, compile-tested | Robustness | Numerical failures in the alpha-cut variable or Catani-Seymour momentum mapping executed `stop 1`, aborting an integration. Programming/flavour errors remain fatal. |
| NLO-F004 | High | FIXED, compile-tested | PDFs | `integrated_beam` evaluated the incoming PDF at `x/z` before checking `z >= x`, so a valid convolution point below support could call the backend with `x/z > 1`. The PDF is now evaluated only inside its physical support. |
| NLO-F005 | Medium | FIXED, tested | Flavour safety | Local `is_quark` treated every non-gluon PDG code as a quark, and integrated helpers admitted flavour zero through `abs(f)<=6`. | NLO-F007 | Medium | FIXED, compile-tested | HAAG phase space | `a1_m1` could leave the mixture selector and function result undefined at exact random-bin boundaries (and accepted invalid `k<2`). Selection is now exhaustive, outputs are initialised, and invalid channels are rejected explicitly. |
| NLO-F008 | Medium | FIXED, compile-tested | Diagnostics | Matrix-element reference checks stored double-precision values in `real(4)` arrays, weakening comparisons and printed diagnostics. They now remain `real(8)`. |
| NLO-F009 | Medium | FIXED, compile-tested | Process handling | `same_flavour` could be read without initialisation in a process-ordering path. It is explicitly initialised to false. |
| NLO-F010 | Low | FIXED, compile-tested | Phase-space inverse | The inverse initial-state helper had a technically undefined `intent(out)` `tau` on its early-return path. The callee now defines it before any return. |

| NLO-F013 | High | FIXED as detection | Process completeness | Integrated pole validation previously accepted `0..nf` complete q-qbar sectors without telling the user that fewer than configured `nf` were present. It now reports the number of affected gluon emitters, the first example, and the `--include_3qqbar` remedy. The permissive policy itself remains NLO-O001. |
| NLO-F014 | Low | FIXED, compile-tested | Amplitude construction | A vertex sign temporary was declared `real(4)` while multiplying double-precision couplings. It is now `real(8)`. |
| NLO-F015 | High | FIXED, integration-tested | PDF performance | Every requested flavour in `integrated_beam` called a wrapper that evolved the complete PDF set, repeating expensive backend work for each history and copy. The convolution now evaluates PDF tables once at `x_beam`, `x_other`, and supported `x_beam/z`, then performs constant-time flavour lookups. The out-of-support table remains zero and the integration histogram/physics closure test passes. |
| NLO-F016 | Medium | FIXED, tested | Dipole registry | Candidate de-duplication used only `(i,j,k)` and could collapse opposite colour orientations when q-qbar clustering produced physical-gluon versus auxiliary-U(1) parents. | NLO-F017 | High | FIXED, tested | Born recycling | `cs_born_pushback_weight` trusted indices and singular radiation measures, allowing out-of-bounds access or division by zero.
